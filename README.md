# Offline

**Built online. Lived offline.**

A public repo about meeting people in person, kept by [InRealLife](https://inreallife.technology). You add to it with a pull request. There are three things to add:

- **The Offline Map** (`map/`): something you'd like to run or join, in your city. If you'd host it, say so.
- **The Manifesto** (`manifesto/`): one line on why meeting in person matters.
- **The Offline Constitution** (`constitution/`): one principle for respectful meetups, with its reason.

How to write each one: [CONTRIBUTING.md](CONTRIBUTING.md).

## What happens to your pull request

1. A check reads your files and says what to fix: folder, fields, length, no contact details, no duplicates.
2. Luc reads every pull request that passes, and merges or closes it with a sentence on why.

A map entry is an idea, not an event. Nothing here is published in the apps. If you wrote `i_would_host: true` in a city we open, we'll write to you.

## No dating entries

The map is public. Dates aren't public listings: in the apps they need a checked selfie and a public venue. So the check refuses dating entries, whatever the city.

## The Constitution and the rules

Principles here shape how we think about meetups. They never override IRL's safety rules and community guidelines, which stay the ones that apply.

## Public, permanent, signed

Everything here is public and stays in the history, signed by your GitHub handle. Don't put anything personal in a file: no address, venue, date, email or phone number. Contributions are under [CC BY 4.0](LICENSE).

Pull requests only: issues and discussions are off, so there's one thing to read.
